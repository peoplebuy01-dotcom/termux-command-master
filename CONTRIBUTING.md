# Contributing

इस guide को नए learners के लिए साफ, सुरक्षित और सही बनाने में मदद करें।

## Contribution rules
1. आसान हिंदी और सरल English terms इस्तेमाल करें।
2. हर command का उद्देश्य और expected output बताएं।
3. Termux/Android version या limitation लिखें।
4. Commands को disposable test directory में जाँचें।
5. Destructive commands के साथ warning दें।
6. Unauthorized access, credential theft, malware या privacy invasion की instructions न जोड़ें।
7. Password, token, email या निजी data commit न करें।

## Suggested lesson format
- Goal
- Prerequisites
- Command and syntax
- Example
- Expected output
- Common errors
- Safety note
- Practice task
