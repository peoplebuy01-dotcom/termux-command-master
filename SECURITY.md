# Security Policy

यह repository education और अपने Android/Termux environment के सुरक्षित उपयोग के लिए है।

## Responsible use
- केवल अपने devices, accounts और systems पर काम करें या स्पष्ट अनुमति लें।
- किसी और का password, token या private data हासिल करने की कोशिश न करें।
- Security examples को isolated learning environment तक सीमित रखें।
- Public repository में secrets कभी न रखें।

## Reporting
किसी documentation में खतरनाक या गलत command दिखे तो repository issue में उसका file path और सुरक्षित reproduction details दें। निजी credentials या संवेदनशील जानकारी न डालें।
