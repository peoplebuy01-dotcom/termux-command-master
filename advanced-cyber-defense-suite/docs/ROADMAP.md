# Advanced Roadmap

The initial release prioritizes safe, read-only defensive checks. Future contributions can add:

1. Structured Android permission inventory through supported Termux:API interfaces.
2. Signed integrity manifests and baseline comparison.
3. CSV/HTML report export with redaction of sensitive values.
4. Local-only practice datasets for log triage and secure configuration review.
5. Optional dependency-free configuration profiles for personal devices.

Any future network feature must remain explicitly authorized, low-impact, documented, and opt-in. No credential attacks, exploitation, stealth, persistence, or malware functionality will be accepted.
