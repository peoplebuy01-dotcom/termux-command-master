# Chapter 24 — Storage और Performance

```bash
df -h
du -sh "$HOME"
du -h -d 1 "$HOME" 2>/dev/null
```

Storage साफ करने से पहले देखें कि कौन-सी files बड़ी हैं। जरूरी project folders और photos का backup लिए बिना delete न करें। Android battery saver background processes रोक सकता है; यह जरूरी नहीं कि Termux की गलती हो।

## अभ्यास
अपने home folder के बड़े subfolders की सूची बनाएँ और केवल पहचान में आए temporary files हटाएँ।
