# Chapter 28 — Developer Tools

कुछ उपयोगी tools:
```bash
pkg install git python nano
git --version
python --version
nano --version
```

Project के हिसाब से compiler या अतिरिक्त packages install करें। हर tool की official help देखें: `tool --help` या `man tool` (अगर उपलब्ध)।

Android पर desktop Linux की हर dependency उपलब्ध नहीं होती। Package install fail हो तो पहले Termux repository में package availability जाँचें।
