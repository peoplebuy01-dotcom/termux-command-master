# Chapter 29 — Project Structure और Documentation

एक साफ project ऐसा हो सकता है:
```text
my-project/
├── README.md
├── src/
├── examples/
├── tests/
└── LICENSE
```

README में उद्देश्य, requirements, install, run, examples और limitations लिखें। Commands को copy-paste करने योग्य रखें और destructive actions की चेतावनी दें।

## अभ्यास
अपने छोटे Bash या Python project के लिए README लिखें।
