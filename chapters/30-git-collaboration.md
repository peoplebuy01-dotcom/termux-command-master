# Chapter 30 — Git Collaboration

```bash
git status
git diff
git add .
git diff --cached
git commit -m "Describe the change"
git log --oneline
git remote -v
```

Shared repository में काम करने से पहले latest changes समझें। Branches अलग काम को सुरक्षित रखने में मदद करती हैं। Force push से दूसरों का काम मिट सकता है; शुरुआती अभ्यास में इससे बचें।

## अभ्यास
अपने notes repo में एक branch बनाएँ, एक file edit करें और commit करें।
