# Chapter 33 — Personal Productivity Tools

Termux से simple personal tools बनाए जा सकते हैं:
- Learning log
- Plain-text task list
- Reading list
- Daily journal
- Backup reminder checklist

पहले plain text से शुरुआत करें। Sensitive journal या private notes को public Git repository में न रखें। Shared storage पर backup रखने से पहले Android privacy settings समझें।
