# Chapter 35 — Final Capstone Projects

अपनी सीख को एक छोटे, documented project में बदलें।

## Capstone options
1. Learning tracker: Python + JSON
2. Notes manager: Bash + text files
3. Backup utility: tar + dated archives
4. Quiz app: Python functions + score
5. Local HTML preview: Python localhost server

## Submission checklist
- [ ] उद्देश्य और user लिखे
- [ ] Installation steps tested
- [ ] Run command tested
- [ ] Example output दिया
- [ ] Error handling जोड़ी
- [ ] Backup/safety note लिखा
- [ ] Secrets हटाए
- [ ] README और license जोड़ा

पहले छोटा version पूरा करें; फिर features जोड़ें।
