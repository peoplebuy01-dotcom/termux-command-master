# Git Notes Project

यह folder Git practice के लिए है।

```bash
cd ~/termux-command-master/projects/09-git-notes
git init
git status
git add README.md
git commit -m "Start Git notes"
git log --oneline
```

इस folder को अलग repo के रूप में practice करें। GitHub पर push करना हो तो अपनी नई repository बनाएँ और उसके URL को remote के रूप में जोड़ें। Credentials को file में न रखें।
